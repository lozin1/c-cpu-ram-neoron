# CPU, RAM, & Neuron Classifier in C

A lightweight, dependency-free implementation of a single-neuron neural network (Logistic Regression) written completely from scratch in C. 

### Features:
- **From Scratch:** No external machine learning libraries used.
- **Gradient Descent:** Custom implementation of forward pass, cost function, and gradient calculations.
- **System Classification:** Classifies CPU and RAM usage patterns into low (0) or high (1) loads.
